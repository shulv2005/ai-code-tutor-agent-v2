# 示例作业

这里的代码是**故意写错的**，专门用来演示「AI 检测 / 生成注释 / 自动改错」三个功能。
每个文件开头都写明了留了哪些错误，可以自己先找一找，再点按钮对照 AI 的结论。

| 文件 | 语言 | 故意留的错误 |
| --- | --- | --- |
| `示例作业/bubble_sort.c` | C | 打印时循环多跑一轮（数组越界）；比较符号写反（排成从大到小） |
| `示例作业/score_stats.py` | Python | 平均分分母写成 `len(scores) + 1`；空列表时取 `scores[0]` 会崩 |
| `示例作业/ScoreManager.java` | Java | `getMax` 初始值取 0，全是负数时会返回错误结果 |

## 怎么用它

1. 双击 `start.bat` 启动服务；
2. 把这三个文件里的任意一个**拖到网页上**（拖到「① 选择你的代码」，或中间的代码预览区），
   也可以打开文件把内容粘进「没有文件？直接粘贴代码」；
3. 依次点「AI 检测」「生成注释」「自动改错」看效果。

> 拖进来的代码只存在于这次浏览里，**不会写进任何文件**。
> 想换一段就再拖一个，或在代码区标题栏点「清空」。
